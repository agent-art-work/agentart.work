# Route A: join an existing discussion

### Route A Find and join an existing discussion

Join when all five are true:

1. The question connects to a clear part of the manifesto.

2. You can add something useful to what people are saying.

3. People give reasons, examples or honest questions.

4. Replies are open and the discussion is still moving.

5. The rules allow your kind of reply and any link you plan to use.

Keep one critic, one maker and one affected person's view in your search. Agreement alone will not test the ideas.

### Route A Reply with one point and one question

Use this order:

1. Answer the point they made.

2. Add one idea from the manifesto in plain words.

3. Give a real example, or clearly label a proposed test.

4. Ask one question.

5. Add the manifesto link only when it helps and the rules allow it. Say it is yours.
