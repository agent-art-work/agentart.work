# Manifesto discourse

One idea → one question and audience → **A join an existing discussion / B create original content** → exchange → record what changed → improve the next attempt.

This is a draft method for learning through discussion. The Agent Art Manifesto is the first case. No outreach or participation trial has been run. The inherited screening is dated 28 October 2026; the [Right Place assessment](cases/agent-art/right-places.md) adds community checks reported on the Discourse Page on 1 November. Neither was independently reverified during its repository import.

1. Read the [principles](method/principles.md) and [workflow](method/workflow.md).
2. Choose [Route A](method/routes/join.md), [Route B](method/routes/create.md), or both.
3. Use the [platform guides](platforms/README.md) and [platform check](templates/platform-check.md).
4. Start with the [Agent Art case](cases/agent-art/README.md) and its proposed first trial.
5. Save selected lessons with the [trial report](templates/trial-report.md).

During search passes, also identify communities, groups and accounts worth following. Assess continued attention, existing discussion access and manifesto publication fit separately. The current Reddit recommendation starts with r/aiwars for discussion, r/ClaudeAI for a concrete Claude project, r/DefendingAI for supporters and r/learnprogramming for optional listening only; see [right places](cases/agent-art/right-places.md) for rules and limits.
